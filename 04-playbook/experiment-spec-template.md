# Experiment spec template

## First follow-up experiment

### Problem

A later gate may improve first-session retention, but the current evidence shows no positive effect.

### Hypothesis

If we add a clearer reward before the gate and keep the gate at level 40, then 7-day retention will improve relative to the existing version because players understand the value of the delay.

### Primary metric

7-day retention

### Secondary metrics

- 1-day retention
- Game rounds in the first 14 days

### Guardrail

No material drop in the share of players reaching the gate.

### Unit of randomization

Player at install.

### Sample size

Use the observed baseline from the project and the decision MDE of 1.0 pp.

### Decision rule

Ship only if the 95% CI lower bound clears the MDE and all guardrails pass.
